# Job photos

Six real photos from the Torres Cleaning Services Facebook page, sourced via
a Google Drive folder the client shared. Filenames were renamed from
Facebook's CDN names to describe what's in each; originals were resized and
re-compressed for the web (see `git log` for the original filenames if you
need to trace one back).

| File | Used for |
|---|---|
| `hero-lawn-farmhouse.jpg` | Hero section background |
| `backyard-mulch-fence.jpg` | Estimate section background |
| `lawn-hedge-driveway.jpg` | Gallery — Mow, edge & blow |
| `hedge-trimming-wall.jpg` | Gallery — Hedge & shrub trimming |
| `paver-walkway-mulch.jpg` | Gallery — Mulch, beds & edging |
| `rock-hosta-bed.jpg` | Gallery — Landscape Design & Installation |

All six are genuine completed jobs, not stock or generated images. If more
become available, the gallery grid (`.gallery` in `index.html`) accepts any
number of `.gallery__tile` entries — add more the same way.
